# Selo do Campeão

Protótipo 2D de arena feito com HTML, CSS e JavaScript Canvas.

## Como jogar
- **PC:** WASD ou setas para mover, mouse para mirar, clique esquerdo para atirar e Espaço para rolar.
- **Celular:** analógico esquerdo para mover, analógico direito para mirar, botão **ATIRAR** para disparar e **ROLAR** para esquivar.

## Sistemas desta versão
- Menu inicial, instruções e créditos.
- Arena com movimentação, mira e projéteis.
- Inimigos perseguidores, corredores, tanques e atiradores.
- Ondas progressivas e chefe na quinta onda.
- Vida, XP, níveis, moedas, loja entre ondas e inventário de seis espaços.
- Rolamento com recarga, partículas, efeitos de impacto e interface adaptada a telas pequenas.

## Publicação
O projeto está preparado para GitHub Pages. Em **Settings → Pages**, selecione **Deploy from a branch**, branch **main** e pasta **/(root)**.
